## Calculator

### My First Basic Project in My Internship

### Python Calculator

This project is a **simple, menu-driven Python calculator** developed as my **first basic project during my internship**.
It allows users to perform basic arithmetic operations through an interactive console-based interface.

---

### Features

* Addition
* Subtraction
* Multiplication
* Division
* Input validation
* Continuous calculations until exit

---

### Concepts Used

* `while` loop
* Conditional statements (`if-elif-else`)
* User input handling
* Error handling using `try-except`

---

### How to Run

1. Save the file as `calculator.py`
2. Open terminal / command prompt
3. Run the command:

```bash
python calculator.py
```
